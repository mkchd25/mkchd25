### Hi, I build [Aptdot](https://www.aptdot.com/): free developer tools that run in your browser

Every Aptdot tool processes your data on your own device. Nothing is uploaded, and the code is open here for you to check.

**Tools**
- [JSON Formatter & Minifier](https://www.aptdot.com/tools/json-formatter-minifier/), [JSON-LD Validator](https://www.aptdot.com/tools/json-ld-validator/) and converters from JSON to [YAML](https://www.aptdot.com/tools/json-to-yaml/), [CSV](https://www.aptdot.com/tools/json-to-csv/), [TypeScript](https://www.aptdot.com/tools/json-to-typescript/), [Python](https://www.aptdot.com/tools/json-to-python/) and [Markdown](https://www.aptdot.com/tools/json-to-markdown/)
- [JWT Decoder & Verifier](https://www.aptdot.com/tools/jwt-decoder/): decode, verify and security-check JSON Web Tokens
- [Mock JSON Generator](https://www.aptdot.com/tools/mock-json-generator/) and [Apt Memo](https://www.aptdot.com/tools/free-online-notepad/), a private online notepad

**Datasets**

[10 free JSON test datasets](https://www.aptdot.com/datasets/) with schemas: security headers, RBAC users, JWT test tokens, MCP configs, CI/CD templates, FHIR patients, an e-commerce catalog, IANA time zones, ISO country and currency codes, and design color tokens.
